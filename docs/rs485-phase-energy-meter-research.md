# Счётчики RS-485 для трёх независимых однофазных зарядок

Дата исследования: 25 сентября 2026 года.

## Задача и границы исследования

Подобрать счётчик с RS-485 для трёх независимых однофазных зарядок в России, с отдельными показаниями мощности и накопленной активной энергии каждой линии для оплаты зарядки пользователями.

Исходный материал: [шаблоны wb-mqtt-serial](https://github.com/wirenboard/wb-mqtt-serial/tree/master/templates). Проверялось содержимое шаблонов ветки `master`, доступное на дату исследования, и документация производителей. Это обзор представленных в репозитории решений, а не всех счётчиков на рынке. Ссылки на `master` изменяются вместе с репозиторием.

Важно различать:

- **Мощность по фазам, Вт/кВт** — текущая нагрузка каждой зарядки.
- **Энергию по фазам, кВт·ч** — накопленные показания для определения расхода за сессию.
- **Пригодность для денежных расчётов** — отдельный вопрос, который не подтверждается одним наличием регистров или шаблона.

## Основной результат

**Главный кандидат среди проверенных готовых шаблонов — «Меркурий 230» в исполнении с RS-485.** Его шаблон содержит мощность `P1/P2/P3` и накопленную активную энергию `AP1/AP2/AP3` каждой фазы.

**WB-MAP технически поддерживают пофазную энергию, но их пригодность для расчётов за зарядку не подтверждена.** Производитель позиционирует эти устройства как средства технического учёта и указывает на ограничения коммерческого применения.

Для «Меркурия 230» также остаётся обязательная для окончательного выбора проверка: распространяются ли утверждение типа и поверка выбранного исполнения на использование его пофазных показаний как трёх самостоятельных расчётных каналов. В рамках исследования это не было подтверждено. Безусловного вывода «один прибор уже разрешён для расчётов с тремя клиентами» нет.

«Нет в шаблоне» означает отсутствие готового канала опроса. Это не доказывает отсутствия функции у самого прибора или у всех его исполнений.

| Меркурий 234 | Да | Нет в штатном шаблоне | Проверить конкретное исполнение и возможность расширения шаблона |

| Энергомера CE308 | Да | Нет в шаблоне; энергия суммарная | Готовый шаблон задачу не закрывает |
| Милур 305 | Да | Нет в шаблоне; энергия суммарная | Готовый шаблон задачу не закрывает |
| Нева МТ32x | Да | Нет в шаблоне; энергия суммарная | Готовый шаблон задачу не закрывает |
| LUNA, трёхфазный | Нет в шаблоне | Нет в шаблоне; энергия суммарная | Требуется дальнейшая проверка и доработка |
| CSQ PD561Z | Да | Каналов энергии в шаблоне нет | Готовый шаблон задачу не закрывает |

## Меркурий 230: варианты для рассмотрения

Для прямого включения рассматриваются:

| Исполнение с RS-485 | Базовый / максимальный ток | Примечание |
|---|---|---|
| Меркурий 230 ART-01 RN | 5(60) А | По максимальному току достаточно для зарядки до 32 А на каждой фазе |
| Меркурий 230 ART-02 RN | 10(100) А | Вариант с большим максимальным током |

В каталоге производителя исполнения обозначены как `С(R)N`: при заказе нужен именно вариант **R, RS-485**, а не CAN. Точный состав функций и совместимость чтения пофазной энергии следует подтвердить для заказываемого исполнения и версии прибора.

Источники: [каталог исполнений с RS-485](https://www.incotexcom.ru/model/interface/rs-485-13), [страница Меркурий 230 ART](https://www.incotexcom.ru/catalogue/230art).

Каналы готового шаблона:

| Каналы | Назначение |
|---|---|
| `P1`, `P2`, `P3` | Текущая активная мощность каждой фазы |
| `AP1`, `AP2`, `AP3` | Накопленная активная энергия каждой фазы |
| `Total consumption` | Общий расход для сверки |

Энергия читается из накопительных показаний счётчика, а не вычисляется контроллером интегрированием периодических замеров мощности. Пофазное чтение энергии подтверждается [руководством Меркурий 230](https://doc.incotexcom.ru/hardware/230/) и примерами в [руководстве конфигуратора](https://www.incotexcom.ru/files/em/docs/config-mercury-uni.pdf).

Используется собственный протокол **«Меркурий»**, не Modbus. Драйвер `wb-mqtt-serial` его поддерживает. [Описание протокола производителя](https://doc.incotexcom.ru/protocol/mercury/).

## WB-MAP: возможности и ограничения

### WB-MAP3E

Поддерживает отдельные `AP energy L1/L2/L3`, RS-485/Modbus и сохранение накопленных показаний при отключении питания. Производитель указывает номер в реестре СИ **79082-20**, но назначение прибора — **технический учёт**. [Карточка WB-MAP3E](https://wirenboard.com/ru/product/WB-MAP3E/).

### WB-MAP3ET

Пофазная энергия есть. В отличие от WB-MAP3E, производитель прямо указывает, что WB-MAP3ET **не включён в реестр средств измерений**, и для проектов с поверкой предлагает WB-MAP3E с внешними трансформаторами. [Каталог производителя](https://wirenboard.com/ru/catalog/wb-map-energy-meters/).

### WB-MAP12E

Поддерживает многоканальное измерение, включая пофазную энергию. Для трёх линий технически подходит, но возможности прибора избыточны. [Карточка WB-MAP12E](https://wirenboard.com/ru/product/WB-MAP12E/).

### Расчётное применение

Техподдержка производителя пишет: «Приборы WB-MAP для коммерческого учёта не подойдут». [Ответ техподдержки](https://support.wirenboard.com/t/podklyuchenie-schetchika-map3et-v-seti-s-izolirovannoj-nejtralyu/32228).

Это не юридическое заключение о любой форме платной услуги зарядки. Однако имеющихся данных недостаточно, чтобы рекомендовать WB-MAP как подтверждённое расчётное решение для данного проекта. Запись в реестре СИ сама по себе не подтверждает пригодность любой схемы применения.

## Допустимость показаний для оплаты

Для измерений в сфере государственного регулирования применяются средства измерений утверждённого типа с действующей поверкой и соблюдением применимых метрологических требований. [Статья 9 Федерального закона № 102-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_77904/d672b2bc12ea6fd5a1e348296701bc6da1be6060/).

До окончательного выбора одного трёхфазного прибора необходимо проверить:

1. Описание типа и методику поверки конкретного исполнения: охватывают ли они пофазные показания энергии, используемые для оплаты трёх отдельных зарядок.
2. Действующую поверку конкретного экземпляра.
3. Поддержку накопленной энергии каждой фазы по RS-485 в заказываемом исполнении.
4. Соответствие фактической схемы измерения эксплуатационной документации: каждый измерительный канал должен учитывать только соответствующую зарядную линию.

Поддержка регистров `AP1/AP2/AP3` подтверждена на уровне шаблона и документации семейства. Их допустимость как трёх самостоятельных расчётных каналов для конкретного исполнения в рамках исследования **не подтверждена**.

## Рекомендация для проекта

- Если принципиален **один трёхфазный прибор**, продолжить выбор **Меркурий 230 ART с RS-485**, предварительно подтвердив расчётный статус пофазных каналов.
- Если приоритет — однозначный раздельный учёт трёх клиентов, рассмотреть **три поверенных однофазных расчётных счётчика с RS-485**, по одному на зарядку. Конкретные однофазные модели в этом исследовании не подбирались.
- Контроллер Wiren Board можно использовать для сбора показаний в обоих вариантах; для этого не требуется выбирать измеритель производства WB.

Для каждой зарядной сессии:

**Расход, кВт·ч = накопленное показание соответствующей линии в конце сессии − показание в начале сессии.**

Мгновенная мощность используется для контроля нагрузки. Она не заменяет накопительный учёт энергии для определения расхода за сессию.
